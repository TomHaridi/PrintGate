## 与小程序不完全一致的地方（说明）

1. **微信专属能力换成 iOS 等价物**：`wx.login` 静默登录 → 账号密码登录；聊天记录选文件 → 系统「文件」App 选择；扫码 → 相机扫码（`mobile_scanner`）。
2. **分片上传阈值**：小程序 8MB（受 `wx.uploadFile` 限制），iOS 按 8MB 同样处理，服务端接口一致。
3. **保存到相册**：iOS 首次调用会弹系统相册权限，被拒后引导去「设置 → PrintGate」开启。
4. **后台导出/打印记录来自同一套 `/api/mp/*`**，所以两台设备看到的数据一致。
