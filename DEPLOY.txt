────────────────────────────────────────
二、跑起来（3 步）
────────────────────────────────────────
1) 构建镜像（当前目录执行）
   docker build --platform linux/amd64 -t printgate:alpine .

   ★ 只改了前端（web/）却看不到变化时，Docker 会复用旧的前端层。
     加 CACHEBUST 强制重编前端：
     docker build --build-arg CACHEBUST=$(date +%s) -t printgate:alpine .

   ★ 换了镜像后记得重建容器，否则容器还挂在旧镜像上（docker ps 不会提示）：
     docker rm -f printgate && docker run ... printgate:alpine
     验证：docker exec printgate grep -c 'history/clean' /app/src/routes/printers.js（应返回 1）

   ARM 设备（N1 / 树莓派 / armbian）：
   docker buildx build --platform linux/arm64 -t printgate:alpine . --load

2) 启动
   docker run -d --name printgate --restart unless-stopped \
     -p 8080:8080 -p 631:631 \
     -v "$PWD/data:/data" -v "$PWD/cups:/etc/cups" \
     printgate:alpine

   或：docker compose up -d --build

3) 打开 http://127.0.0.1:8080
   首屏是初始化向导，设置管理员密码（≥8 位，含字母和数字）后自动进入后台。

端口说明：
  8080  管理台 + 全部 API（小程序也连这个）
  631   IPP / AirPrint（可选；若本机已有 CUPS 占用可去掉这个映射）
  9100  虚拟打印机接收器（仅本地测试用，可不映射）

────────────────────────────────────────
三、首次配置顺序
────────────────────────────────────────
① 打印机
   自动扫描：mDNS + CUPS 枚举 + 网段探测（会对 631/443 做 IPP 握手，识别真实型号与 /ipp/print 路径）
   ★ 扫描范围很重要：容器是桥接网络，默认只能看到 Docker 内网（172.17.x）。
     请把「扫描范围」改成路由器的局域网网段，例如 192.168.1.0/24（支持多个，逗号分隔），保存后快速扫描也会用它。
   ★ 还是扫不到：用抽屉里的「手动探测」直接输入打印机 IP，识别到就能加。
   深度扫描：额外探测 443(IPPS) 与 515(LPD)，适合关掉 mDNS 的老机器。

   扫描完成后会自动弹窗「发现打印机，是否自动安装驱动？」：
     - 默认按型号自动匹配驱动（IPP Everywhere 优先，其次 PCL/PostScript 通用驱动，最后 RAW）
     - 勾选后点「自动安装并添加」即可批量建队列
     - 单台驱动不理想 → 「更换驱动…」：推荐 / 本地驱动库 / 在线驱动库(OpenPrinting) / 上传 PPD 或直链
     - everywhere 失败会自动回退 PCL/PS 通用驱动，并在结果里注明

   手动添加：ipp://IP/ipp/print（免驱）或 socket://IP:9100（RAW/PCL），驱动会按地址自动切换
   没有实体打印机可点「创建虚拟打印机」，打印结果落在 data/spool/

   ▸ 历史清理（打印机页右上角「历史清理」按钮）
     打开即看到四项占用：任务记录（已完成/全部，进行中保留）、CUPS 已完成作业、
     虚拟打印机落盘、源文件与扫描件。
     可选范围：任务记录 / CUPS 作业 / 落盘文件 / 源文件 / 扫描记录，
     可选保留期：全部 / 1 / 3 / 7 / 30 / 90 天。
     清理只删历史与落盘文件，正在打印和待审批的任务不受影响；
     被未完成任务引用的源文件会自动跳过，点「立即清理」后提示释放了多少磁盘。
     下半部分是「自动清理」：开启后每小时按保留天数清理任务、CUPS 与落盘文件，
     每次自动清理都会写一条 auto_cleanup 审计。

   ▸ 发起打印（一页四种模式）
     顶部先选目标打印机，右边实时显示 CUPS 状态与打印机是否空闲。

     · 标准打印：拖拽上传 PDF / 图片 / Word / Excel / PPT / TXT，或从最近上传里挑。
     · 文字速印：直接粘贴或输入文字，按字号/行距/页边距排成 PDF，自动换行与分页。
       适合打取件码、交接单、地址条这类没有源文件的场景（中文字体已内置）。
     · 发票打印：多选发票图片，按「每页 1 / 2 / 4 张」自动拼到 A4（默认 2 张）。
     · 身份证打印：上传人像面与国徽面，按原比例居中排在同一张 A4 上，沿边框剪开即可。

     打印参数：颜色（彩色/黑白）、双面（长边/短边翻页）、份数；「高级选项」里还有
     纸张大小、介质类型、打印质量、进纸盒（这些下拉会读打印机驱动的真实可选项，
     点「刷新选项」重新拉取）、缩放、页面范围、每页页数、
     页面子集（全部页 / 奇数页 / 偶数页 / 偶数页倒序）、镜像打印、水印文字与自定义 CUPS 参数。

     水印会叠加到每一页（斜向平铺、浅色不遮正文），PDF、图片、Office 转换件、TXT 都支持。

     右栏三块：预览（含纵向/横向切换与纸张尺寸）、打印记录（最近 5 条，20 秒刷新）、
     打印机状态（队列任务数、型号、墨盒余量、已装纸张）。
     墨盒与纸盒依赖打印机自身通过 IPP 上报，虚拟打印机和老机型可能显示「未上报」，属正常。

② 小程序对接（所有接入参数只在这一页改）
   - AppID / AppSecret
   - 接入地址（BASE）：公网填 https 域名，内网留空则用当前访问地址
   - 管理员 OpenID 白名单（可留空）
   - 三个开关：新用户需审批 / 允许扫码登录 / 开发模式
   保存后点「测试连通性」验证凭据。

②.5 公网访问（小程序要能在外网用）
   打开「中转对接」，五步向导：
     1) 选模式：单端口 443（推荐，wss 复用；小程序只认 https+443）
     2) 填域名与 BASE：https://print.你的域名.com（要已备案）
     3) 填云服务器地址/端口/Token → 页面生成 frps.toml，复制到云上 /etc/frp/frps.toml
        注意：wss 模式不要把 frps 的 transport.tls.force 打开（TLS 由 nginx 终结）
     4) 复制 nginx 片段到云上 conf.d：/~!frp 转发到 127.0.0.1:7000，/ 转发到 127.0.0.1:18080
        client_max_body_size 必须大于「单文件上限」，否则大文件 413
     5) 点「运行自检」：本机服务/打印机/frpc 语法/进程/服务端连通/BASE/公网回连，全绿后勾选「启用 frp」保存
   容器若在 nginx 后面，记得加环境变量 TRUST_PROXY=true，审计才记录真实 IP。

②.7 登录方式与普通用户门户
   登录页两种方式：管理员密码 + 微信扫码（都可在「系统设置 → 安全」单独开关，
   但不能同时关掉）。扫码后按角色自动分流：
     · 管理员微信  → 管理台（全部功能）
     · 已授权普通用户微信 → 打印门户 /portal：只能上传打印、看自己的打印记录、
       一键清空自己的历史（进行中的任务不会被清）
   普通用户访问任何管理页都会被路由挡回门户，调管理接口一律 401/403。
   普通用户有两种方式：① 登录页「普通用户」Tab 用用户名+密码自助注册（推荐，不需要微信）；
   ② 走微信：小程序登录后管理员放行，再用「扫码登录」进门户。两者都受「允许普通用户自助注册」开关控制。
   不想让人自助注册时，在「系统设置 → 安全」关掉「允许普通用户自助注册」：登录页入口消失、
   新微信不再建号；改由「小程序用户 → 添加用户」填 OpenID 手工开号（用户可在小程序资料页复制 OpenID）。
   「隐藏普通用户的详细打印设置」开关打开后，普通用户只能选文件/打印机，
   份数、色彩、单双面、纸张全部按默认（单份 / 黑白 / 单面 / A4）。

③ 绑定管理员微信
   用小程序内「扫一扫」扫页面右侧二维码 → 该微信立即成为管理员
   → 之后登录页「扫码登录」Tab 即可扫码进后台。
   绑定码是**一码一人**：默认 10 分钟有效（BIND_TOKEN_TTL_MIN 可调），
   绑定成功或到期后自动换新，页面倒计时结束后会自己刷新出新码；
   要给第二个微信授权，直接扫页面上新生成的码即可。
   绑不上时先看页面上的码是否刚换过——旧码已失效属正常。

④ 用户审批（未审批不能打印）
   新用户（微信或账号密码）默认待审批：能登录门户、能看自己的记录，但上传/打印会被拒（403 NOT_APPROVED）。
   到「小程序用户」点「通过」后立刻可打印（门户 15 秒内自动解锁）。
   审批通过后，门户右上角「高级打印」进入打印工作台，与管理员「发起打印」同样的全部功能
   （标准/文字速印/发票合排/身份证 + 预览与全部参数），但只能看到自己的文件与任务，
   后台设置照样进不去（系统设置/用户管理/审计/打印机增删全部 401/403）。
   小程序「我的 → 微信一键登录」首次登录会引导用微信头像+昵称补全资料（微信不允许静默读取，
   需要用户点一下头像按钮），后台用户列表按头像+昵称区分申请人。

────────────────────────────────────────
四、从旧数据卷迁移
────────────────────────────────────────
把旧容器数据目录（含 remote-print.db 与 uploads/）挂到 /data 后首次启动，会自动迁移：
管理员密码（明文会在登录时升级为 scrypt）、微信凭据、管理员 OpenID、绑定码、限额、
用户与角色、历史文件与任务（路径自动改写）。
旧 cups-web.db 里的 API Key 哈希不可逆，需在「中转对接」重新生成。
打印机队列在 /etc/cups，把旧容器的该目录挂过来即可保留。

────────────────────────────────────────
五、几个必须知道的点
────────────────────────────────────────
- 反向代理后部署：容器加 -e TRUST_PROXY=true，否则所有请求都记成代理 IP。
  公网直连时千万不要开这个开关，否则可伪造 X-Forwarded-For 绕过登录锁定。
  2.1.1 起加了兜底：请求直接从公网地址进来（对端不是本机/内网）时，即使开了
  TRUST_PROXY 也不采信 X-Forwarded-For，用真实对端地址记账。反代请与本服务
  同机（127.0.0.1）或同内网/容器网络，否则限流会按代理 IP 合并计算。
- 绑定码（小程序扫码升管理员）默认 10 分钟过期、用后即换：BIND_TOKEN_TTL_MIN 可改；
  全站 30 分钟内失败 50 次（BIND_FAIL_ROTATE 可调）会自动换码，正在撞码的旧码当场作废。
- 修改密码会让其他设备的登录立即失效（会话纪元机制）。
- 任务状态：提交成功先显示「打印中」，后台每 8 秒对照 CUPS 队列，出队后转「已完成」；
  队列暂停时会一直显示打印中，不会谎报完成。
- 数据保留期在「系统设置 → 数据与维护」里改，到期自动清理上传件、扫描件与虚拟打印机落盘。
  更细的手动/自动清理在「打印机 → 历史清理」里（可分别清任务、CUPS、落盘、源文件、扫描）。
- Office 文档需要镜像自带 LibreOffice（默认未装），否则上传会提示先转 PDF。
- Alpine 无 ipp-usb / sane-airscan：USB 扫描仪与 eSCAN 网络扫描仪不支持；
  AirPrint 广播在桥接网络下不可用，Linux 主机建议 network_mode: host。
