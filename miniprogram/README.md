# PrintGate 云打印小程序

配套 PrintGate（CUPS 打印网关）后端的微信小程序端：**普通用户上传文件 → 选打印机 → 调参数 → 打印并跟踪记录；管理员在小程序内审批用户与任务、管理打印机、查看并修改全部开放设置项**。本工程只包含小程序端，接口直接调用后端既有 `/api/mp/*` 路由（本次仅在后端 `mp.js` 新增一个管理员清理历史接口，其余零改动）。

> **部署请见 [`部署文档.md`](./部署文档.md)**：容器化部署、打印机接入、小程序 AppID 与合法域名配置、本机/局域网/公网三种网络场景、安全加固清单、升级回滚与排障对照表。

**v5 更新（本轮）：首页四模式发起打印（标准 / 文字速印 / 发票合排 / 身份证）+ 打印预览；管理端新增「打印历史」页与清除记录；扫码绑定管理员；文件预览完善（弹层 + 保存到相册 + 失败重试）；修复隐私弹窗「同意点不了」。**

**v2：全站卡片风格重构 + 暗夜模式。v3：对抗测试修复一批真实 Bug。v3.1：修复文件页 `isImage` 渲染崩溃。v4（本次）：按「Printgate 最终版」后端源码重新核对全部接口契约并适配，修复 7 类适配缺陷（含 1 个 Blocker 级语法错误），检查项扩充至 9 项、冒烟测试 62 项。**

## 3. 快速开始

1. 微信开发者工具 → 导入本目录（`project.config.json` 所在目录）。
2. 填写 PrintGate 服务端地址，**两个入口等价**：
   - **登录页**底部「服务地址配置」→ 弹层里填地址 → 「保存并重新连接」，保存后自动重试登录；
   - 登录后「我的 → 服务地址」。
   - 本机联调：`http://127.0.0.1:8080`（需在开发者工具「详情 → 本地设置」勾选**不校验合法域名**）；
   - 局域网：填后端主机的局域网 IP + 端口，如 `192.168.1.10:8080`（缺协议会自动补 `http://`）；
   - 线上：已备案的 https 域名。
   - 默认值来自 `config/index.js` 的 `current`（当前为 `dev`）。
3. 登录失败的提示会**带上当前正在连接的地址**，方便判断是地址写错还是后端没起。
4. 首次进入自动完成 `wx.login` 登录；新用户默认待审批，管理员在后台或小程序「用户审批」中授权后即可打印。

## 4. 卡片风格与暗夜模式

### 卡片风格

- 全站统一「分区标题 + 圆角卡片」语言：`section-cap`（分组标签）+ `card`（28rpx 圆角、柔和投影、24rpx 页边距）。
- 发起打印页参数区拆为 **基本 / 纸张与版式 / 高级** 三张卡；「我的」页每条菜单独立成卡；管理台概览为 **Bento 网格**（2 大 + 4 小 + 2×2 入口）。
- 卡片内次级面用 `--pg-card-2`，控件（分段 / chips / 输入）统一 `--pg-fill` 底，选中态 `--pg-primary-soft`。

### 暗夜模式

- 「我的 → 显示与主题」三档：**跟随系统 / 浅色 / 深色**，选择即时生效并本地持久化（`pg_theme_mode`）。
- 实现方式：`app.wxss` 在 `page` 定义浅色 token、`.theme-dark` 覆盖全部 token；每个页面根节点挂 `theme-dark` 类；组件内部**自包含同一套 token**（`components/*/*.wxss`），并通过 `pageLifetimes.show` 在页面再次显示时同步，避免长驻组件主题滞后。
- 切换时同步：tabBar 配色（`wx.setTabBarStyle`）、状态栏文字色（`wx.setNavigationBarColor`）、页面背景含下拉回弹区（`wx.setBackgroundColor`）。
- 暗夜配色通过 WCAG 对比度校验：正文 13.5:1、主色 6.2:1、语义色标签均 ≥ 5:1。
- 图标（tabBar / UI）采用明暗双背景均可辨的中间色调，无需为暗夜单独维护图标集。

### 主题色（可自定义）

- 「我的 → 显示与主题 → 主题色」提供 **7 种预设**：青绿（默认）/ 海蓝 / 碧蓝 / 罗兰紫 / 暖橙 / 玫红 / 石墨。点选即时生效，本地持久化（`pg_primary`）。
- 实现方式：页面根节点内联 `style="{{primaryStyle}}"`，由 `utils/theme.js` 一次性注入整组派生 token——`--pg-primary` / `-deep` / `-bright` / `-soft` / `-softer` / `-on-primary`。CSS 自定义属性会继承进组件内部，因此弹窗、标签、空态等组件同步换色；组件里的 `var(--x, 兜底色)` 只在脱离注入上下文时兜底。
- 深浅由主色实时算出：与黑白混色得 `-deep`/`-bright`，`10%`/`5%` 透明度得 `-soft`/`-softer`，按 WCAG 相对亮度自动选主色上的文字为白或深色。所以新增预设只需加一个色值，无需补任何配套色。
- 暗夜下主色自动提亮一档（混 14% 白），避免在深色底上发闷；tabBar 选中色同步使用提亮后的主色。
- 非法色值（非 `#RRGGBB`）一律回落默认青绿，不会把页面配色搞花。

## 10. 常见问题

- **登录提示"网络异常，请检查服务地址或网络"**：先看提示末尾的「当前：xxx」——那就是正在连的地址。默认是 `http://127.0.0.1:8080`，确认 PrintGate 容器是否已启动（`docker compose up -d`）、端口是否一致；真机/局域网把地址换成后端主机 IP。改完点登录页「服务地址配置 → 保存并重新连接」即可。
- **登录提示"请先配置服务地址"**：点登录页「服务地址配置」填写后端地址后保存。
- **真机/预览登录失败**：`project.config.json` 的 `appid` 目前是 `touristappid`（游客模式）。正式登录必须换成与后台「小程序对接」页一致的 AppID，否则 `wx.login` 的 code 无法 `code2session`。
- **暗夜模式下想固定浅色**：「我的 → 显示与主题 → 浅色」。
- **上传失败/超时**：检查服务地址、网络与后台文件大小上限（系统设置里可调）。
- **提示"账号待管理员授权"**：新用户默认待审批，请先完善资料，再联系管理员授权。
- **打印一直"打印中"**：CUPS 队列 6 小时未完成会被标记失败，请检查打印机与 CUPS 服务状态。
- **预览只有首页**：预览接口返回的是原图或**首页渲染 PNG**（非图片文件由服务端 `pdftoppm` 生成），不是完整文档阅读器；需要全文请下载原文件。
- **文件列表显示"源文件已清理"**：超过保留期后源文件被自动清理，仅保留记录；重新上传即可再打印。

- **整套图标重做**：底部导航与页面内图标统一为 24×24 网格、1.7px 描边、圆角端点的线性风格，
  主色 `#0C8B80`。图标由 `tools/gen-mp-icons.js` 用 SVG 程序化生成，改风格/换色不用重新找素材。
- **服务地址支持扫描局域网**：登录页「服务地址」弹层里新增「扫描局域网」。
  小程序没有 raw socket，拿不到本机 IP/网关，也不能发 UDP 广播，所以这里的"扫描"是
  **对候选地址逐个请求 `/api/health`**：常见私有网段（192.168.0/1/2/3/4/31、10.0.0/0.1/1.1、172.16.0）
  × 常见主机位（.1/.254 网关位 + .2/.10/.50/.100/.101/.102/.110/.200）× 常见端口（8080/80/8000/3000），
  8 并发、单请求 800ms 超时，命中后返回里的 `app=PrintGate` 才算数，点一下即填入并连接。
  已知网段可直接填 `192.168.1.` 前缀，会扫该段 1-254。
  **真机限制**：微信只允许请求备案过的 https 域名，局域网 http 会被域名校验拦掉，
  所以扫描要在开发者工具（勾选「不校验合法域名」）或真机调试模式下用；生产环境请直接填 https 域名。
- **地址记忆**：最近用过的 5 个地址存本地（`pg_base_urls`），登录成功、扫描命中、手动保存都会记；
  弹层里「最近使用」点一下就重连，更新小程序/清缓存后不用重填。
  真机上不再默认 `127.0.0.1:8080`（那个地址真机永远连不上），改为留空引导扫描；开发者工具仍保留默认值。
- **免二次填写进入**：地址与 token 都在本地时，启动直接进首页（`onLoad` 里 `goHome()`），不再停在登录页。
